# ActiveCampaign LTV Segmenter v3

Marketing agencies running complex email sequences cannot dynamically segment contacts in ActiveCampaign based on their real-time Lifetime Value (LTV) tracked in Stripe. Standard integrations sync basic purchase events but don't recalculate cumulative LTV shifts (e.g., moving a customer from a 'Mid-Tier' list to a 'VIP/High-Value' list when they cross a $1,000 threshold). Agencies waste hours manually exporting CSVs from Stripe and re-uploading them to update ActiveCampaign tags. (Target customer: Direct-to-Consumer (DTC) Marketing Agencies)

## Running

Open index.html for the landing page; app.html is the working tool.
